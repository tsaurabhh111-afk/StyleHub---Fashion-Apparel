# StyleHub – Fashion & Apparel

A responsive fashion e-commerce internship project built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Responsive home page
- Men, Women and Kids categories
- Product listing with search, category, size and price filters
- Product detail page with size selection
- Cart with quantity adjustment and automatic price calculation
- Simulated checkout
- Simulated login/account
- Wishlist interaction
- About page
- LocalStorage-based cart persistence
- No database required

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Tech
HTML5, CSS3, JavaScript (ES6), LocalStorage
